# Datasets

This directory contains four categories of Urdu document datasets collected and prepared as part of the **Orator-OCR** project.

The datasets cover different document types and image conditions to support Urdu Optical Character Recognition (OCR) research, development, and evaluation.

## Dataset Categories

### 1. Printed / PDF Dataset
**Directory:** `printed_pdf/`

Contains digitized printed Urdu book pages, along with OCR-generated text, aligned text, and manually corrected annotations.

### 2. Handwritten Dataset
**Directory:** `handwritten/`

Contains handwritten Urdu document images and their corresponding Google OCR outputs, manually aligned text, and corrected annotations.

### 3. Camera-Captured Dataset
**Directory:** `Camera-Captured/`

Contains Urdu document images captured using cameras under different conditions, along with OCR outputs, aligned text, and corrected annotations.

### 4. Historical Dataset
**Directory:** `historical/`

Contains historical Urdu document images representing variations in paper condition, discoloration, and document quality, along with their associated text data and annotations.

## Dataset Organization

Each category has its own directory and README file describing its collection, characteristics, preparation workflow, and annotation stages.

The datasets include multiple text-processing stages, where available:

- **Original Images:** Source Urdu document images.
- **Google OCR Output:** Initial machine-generated text.
- **Aligned Text:** Text manually aligned with the corresponding document content.
- **Corrected Text:** Manually reviewed and corrected annotations.

## Data Annotation Contribution

The dataset preparation involved collecting Urdu document images, obtaining initial OCR output, manually aligning extracted text, and reviewing and correcting annotations.

These preparation stages provide useful resources for studying OCR performance and the quality of machine-generated text compared with manually reviewed annotations.

## Project Context

These four dataset categories were developed as part of the Orator-OCR project, which focuses on Urdu document recognition across printed, handwritten, historical, and camera-captured materials.

## Notes

The repository contains the uploaded dataset files and their documentation. Collection statistics reported in the project thesis describe the overall project datasets and may differ from the number of files available in this repository.

Only data authorized for public distribution should be included in this repository.
