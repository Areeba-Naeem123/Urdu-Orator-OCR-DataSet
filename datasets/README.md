# Datasets

This directory contains the four Urdu document categories associated with the Orator-OCR project.

- `printed_pdf/` — Printed and PDF-based Urdu documents.
- `handwritten/` — Handwritten Urdu documents and their text annotations.
- `camera_captured/` — Urdu documents captured using cameras.
- `historical/` — Historical Urdu document images.

Dataset files will be added after reviewing their organization and sharing permissions.
